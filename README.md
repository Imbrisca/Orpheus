▶️ Step-by-Step: How to Run

1. Install dependencies

pip install yt-dlp --break-system-packages
sudo apt update
sudo apt install ffmpeg

2. Go to your project folder

cd orpheus

3. Create and edit "link.txt"

nano link.txt

Paste your YouTube links (one per line), then save.

4. Run the script

python3 orpheus.py

5. Done

Your MP3 files will appear in the output folder defined in the script.
